# ثيم نسيم — Naseem

ثيم لمنصة سلة مبني على محرك Twilight (ومبني فوق ثيم رائد المفتوح المصدر من سلة).

## الجديد في نسيم
- هيدر باللوجو في المنتصف والقائمة تحته، وسطر صغير تحت اللوجو
- شريط عروض متحرك أعلى الصفحة (من إعدادات الثيم)
- شريط تنقل سفلي في الجوال
- فوتر باللوجو في المنتصف
- أقسام جديدة للصفحة الرئيسية: بانر رئيسي، أقسام متحركة، ماركات متحركة، فيديوهات قصيرة، أرقام المتجر، أسئلة شائعة
- حركات ظهور ناعمة مع التمرير، وبتتوقف لو الزائر مفعّل تقليل الحركة
- خطوط تجوال و IBM Plex Sans Arabic، وشكل حواف قابل للتغيير

كل التنسيقات الخاصة بنسيم في: `src/assets/styles/06-theme/naseem.scss`

## التشغيل
```
pnpm install
salla theme preview
```
